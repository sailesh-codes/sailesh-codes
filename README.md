## What I Work On

- **AI Agent Systems** — Building agent-powered products using LLM APIs, tool calling, memory, RAG, and streaming UIs.
- **Agent Architecture** — Designing modular agents for planning, code generation, validation, retrieval, and execution.
- **Web Application Firewalls** — Exploring WAF concepts such as request filtering, rate limiting, bot protection, security rules, and attack prevention.
- **Security Engineering** — Exploring secure authentication, API protection, dependency scanning, secret management, and vulnerability-aware development.
- **Testing & Performance** — Using Playwright, Cypress, k6, and automated checks to validate user flows, APIs, and system performance.
- **Full-Stack Applications** — Developing scalable web products with Next.js, TypeScript, Node.js, Supabase, and modern UI systems.
- **Engineering Operations** — Connecting monitoring, testing, security checks, deployments, and alerts into practical developer workflows.
- **Reliable Delivery** — Using CI/CD, Docker, cloud deployment, and quality checks to ship dependable client products.
